# S6 প্ল্যান — Books + Tier B পলিশ (ধাপে ধাপে)

> প্রতিটি ধাপ: রিসার্চ → স্কোপ → acceptance → তারপর কোড। ড্যাশবোর্ডের কার্ড/টোকেন রিইউজ।

## S6.1 — Search picker step indicator ✅ (এই কমিট)
**রিসার্চ:** ৪-ধাপের ফ্লোতে ইউজার জানে না কোথায় আছে; প্রফেশনাল পিকার (Duolingo/Khan) স্টেপ প্রগ্রেস দেখায়।
**স্কোপ:** পিকারের উপরে ৩-স্টেপ ইন্ডিকেটর: **ক্লাস → অধ্যায় → টাইপ** (a=identity always done).
**Acceptance:** অধ্যায় বাছলে ২ নম্বর, টাইপ বাছলে ৩ নম্বর সক্রিয়; bn/en; স্ক্রিনে জায়গা বাড়ে না।

## S6.2 — Guide answer sticky bar
**রিসার্চ:** উত্তর স্ক্রল করে নামলে প্রাইমারি অ্যাকশন হারায়। **স্কোপ:** নিচে sticky “ব্যাখ্যা/চ্যাট” বার। **Acceptance:** যেকোনো স্ক্রলে অ্যাকশন দেখা যায়।

## S6.3 — Creative parts sticky nav

## S6.4 — Chapter questions filter bar
**রিসার্চ:** ফিল্টার স্ক্রলে হারায়। **স্কোপ:** sticky search+type chips + কাউন্ট।
