## A10–A12 বিস্তারিত

### A10 — Subjects forever loading
- কারণ: `subjectsAsync` → `withBulkGuideFlags` ১০s timeout; তিনটি REST কলে আরও ১০s → ~৩০s পর্যন্ত “লোড হচ্ছে”।
- সমাধান: (1) flags কল ৩s timeout + ব্যর্থ হলে per-subject probe পরে, (2) সাবজেক্ট লিস্ট আগে রেন্ডার, flags এলে ব্যাজ আপডেট, (3) skeleton দেখাও, “লোড হচ্ছে…” টেক্সট নয়।

### A11 — ভুল empty copy
- “শেষ যেখানে পড়েছ” সেকশনে `noWeakYet` দেখাচ্ছে; আলাদা কী: `noLastStudied` = “এখনো কোনো লেসন খোলা হয়নি — প্রশ্ন খুঁজে শুরু করো”।

### A12 — Home নিচের অংশ প্রফেশনাল
- এক `SectionHeader` + এক `AppCard` স্টাইল; সপ্তাহের চার্ট = ৭টি বার (উচ্চতা ভিন্ন), আজকের বার হাইলাইট, নিচে দিন-লেবেল, ডানে “১/৭ দিন”; খালি দিন muted।
- প্ল্যান রো: বৃত্ত আইকন (সম্পন্ন হলে brand check), ডান পাশে ছোট chevron; সম্পন্ন হলে টেক্সট muted।
- শেষ পড়া/বই: এক-লাইন meta + ডান পাশে CTA; কার্ড প্যাডিং ও গ্যাপ এক।

## বিস্তারিত

### A3 — দৈনিক কুইজ
- **কারণ:** guide daily set fetch (Edge) ধীর বা খালি; UI অপেক্ষা শেষে bank fallback ডায়ালগ দেখায় — ইউজার ভাবে আটকে গেছে।
- **সমাধান:** (1) ২.৫s-এ “ব্যাংক সেট দিয়ে শুরু” ডায়ালগ আগেভাগে, (2) রেসপন্স এলে গাইড সেট প্রস্তাব, (3) স্পিনারে “গাইড প্রশ্ন আনা হচ্ছে…” টেক্সট, (4) ব্যর্থ হলে সরাসরি ব্যাংক কুইজ।
- **টেস্ট:** fake Edge দেরি → ২.৫s-এ ডায়ালগ; দ্রুত → গাইড সেট।

### A4 — সব বিষয়ের প্র্যাকটিস
- **কারণ:** `practice_home_view`-এ হার্ডকোড math/science কার্ড।
- **সমাধান:** `booksService.subjectsAsync(class)` → সব unlocked/guide সাবজেক্টের টাইল (আইকন+রঙ), ট্যাপে `_startPractice(subject)`।
- **টেস্ট:** ৫+ বিষয়ের তালিকা রেন্ডার।

### A5/A6 — মডেল টেস্ট
- **কারণ:** subject শুধু session থেকে; সার্ভার fail হলে শুধু মেসেজ।
- **সমাধান:** উপরে সাবজেক্ট চিপ/ড্রপডাউন; লোড ব্যর্থ হলে **Retry**; ক্যাশ থাকলে সেট দেখাও।
- **টেস্ট:** ভিন্ন সাবজেক্ট বাছলে সেই সেট; ভুল সার্ভার → retry।

### A7 — Prev বাটন
- **কারণ:** `OutlinedButton` (min 88×56) শুধু আইকন নিয়ে বড় খালি বক্স।
- **সমাধান:** `IconButton.filledTonal(icon: arrow_back, 44×44)` বা 40px outlined circle; বাকি আইকনগুলোর মতো।

### A8 — আজকের পরিকল্পনা
- **কীভাবে কাজ করবে:** দিনের তারিখ (hash) + বর্তমান state → ৩টি টাস্ক রোটেট:
  streak quiz (কুইজ না হলে), weak revision (weak>0), goal (goal<100%), model test (শনি/রবি), saved revision (সেভ থাকলে)।
- **done persist:** প্রতিটি টাস্কের জন্য আজকের key; সম্পন্ন হলে ✓ ও পরের দিন নতুন।
- **টেস্ট:** দুই ভিন্ন তারিখে ভিন্ন টাস্ক-সেট।

### A9 — সাপ্তাহিক বার
- **কারণ:** `activityDates`-এর ফরম্যাট (ISO/`yyyy-m-d`) ভিন্ন হলে ম্যাচ মিস।
- **সমাধান:** year-month-day নরমালাইজ করে তুলনা (আগেই করা) + ইউনিট টেস্ট।
