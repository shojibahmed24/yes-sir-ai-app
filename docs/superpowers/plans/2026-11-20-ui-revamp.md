# UI Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, cheapest) or superpowers:subagent-driven-development. Steps use `- [ ]` checkboxes.

**Goal:** অ্যাপের সব UI স্ক্রিনকে professional, হালকা colorful, সাবজেক্ট-কালারড ও animated কিন্তু দ্রুত করে তোলা — ব্যবহৃত বিদ্যমান ডিজাইন সিস্টেম দিয়েই।

**Architecture:** নতুন প্যালেট/ফ্রেমওয়ার্ক নয়। `lib/theme`-এর টোকেন (`Sp`/`Rad`/`Elev`/`IconSize`/`MotionTokens`), কম্পোনেন্ট (`AnimatedCard`/`StaggeredList`/`ShimmerCard`/`AnimatedProgress`/`AppStateView`/`SectionHeader`), `AppTheme.subjectColorFor` ও গ্রেডিয়েন্ট — এগুলো **সব স্ক্রিনে ধারাবাহিকভাবে প্রয়োগ** করা হবে।

**Tech Stack:** Flutter (built-in animation), `go_router`, page-wise l10n (`lib/l10n/pages/*`), no new dependency.

**Spec:** `docs/ui-revamp-plan.md` (design + অডিট) — এই প্ল্যান সেই স্পেক থেকে লেখা।

**অবস্থা (২০২৬-১১-২০, main `85d60f4`):** Task 1–4 সম্পন্ন; 5d/5e সম্পন্ন; নতুন তিনটি
স্ক্রিন (subject detail, today, achievements) সম্পন্ন; Task 7 সম্পন্ন; 5a home
entrance ও 5c lesson hub সম্পন্ন; Phase 7-এর profile ও parent dashboard সম্পন্ন।
**বাকি (ঐচ্ছিক):** 5b search-flow/list রো accent; settings/premium/voice টিউচার
পলিশ (settings ফাইল ২৫০-এ পূর্ণ, তাই আগে ভাগ করতে হবে)।

## Global Constraints

- প্রতি Dart ফাইল ≤ ২৫০ লাইন (target ১৫০–২০০)।
- সব UI লেখা bn/en, `l10n/pages` ম্যাপে; হার্ডকোড টেক্সট নয়।
- মোশন শুধু `MotionTokens` থেকে; `reducedMotion(context)` হলে কোনো মোশন নয়।
- রঙ শুধু `AppTheme`/`DarkPalette`/`LightPalette`; ফিচার-ফাইলে নতুন `Color(0x…)` নয়।
- WCAG AA: টেক্সট কনট্রাস্ট ≥ 4.5:1; গ্রেডিয়েন্টের ওপর শুধু সাদা bold হেডার।
- কোনো নতুন dependency, DB write, secret, Play publish, ফাইল ডিলিট নয়।
- প্রতি task শেষে: `flutter analyze` (০ error/warning) + `flutter test --concurrency=1` (সব সবুজ), তারপর commit।

## Review Focus

1. **Reduced-motion ইউজার:** অ্যানিমেশন বন্ধ থাকলেও প্রতিটি স্ক্রিনের সব কনটেন্ট অবশ্যই দেখা যাবে (opacity 0-এ আটকে না থাকে)।
2. **বাংলা টেক্সট ওভারফ্লো:** বড় লেখা/১.৩x ফন্ট স্কেলে কার্ড/চিপ ভাঙে না (বর্তমান `subject_tile_overflow_test` ধারা বজায়)।
3. **খালি/এরর অবস্থা:** প্রতিটি নতুন স্ক্রিনে honest empty/error state; কোনো ভুয়া সংখ্যা নয়।
4. **লিস্ট রেন্ডার পারফরম্যান্স:** বড় লিস্ট (>৫০ রো) lazy builder-এ থাকে; stagger শুধু প্রথম ৬ আইটেমে।
5. **ডার্ক মোড:** সব নতুন accent/gradient ডার্কে পড়া যায় (light-only রঙ নয়)।
