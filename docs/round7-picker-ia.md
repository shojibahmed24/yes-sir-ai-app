# রাউন্ড ৭ — পিকার IA: বিষয় → ক্যাটাগরি → লেসন → ৪ ফর্ম

## সিদ্ধান্ত (আপনার অনুমোদিত)
- **মডেল টেস্ট:** যে বিষয়ে সেট **বিষয়-ওয়াইড** (গণিত, বাংলা ২য়, ইংরেজি ১ম/২য়) → লেসন তালিকার শেষে একটাই এন্ট্রি; যে বিষয়ে **লেসন/অধ্যায়-ট্যাগড** সেট (বাংলা ১ম, ICT) → সেই লেসনের মধ্যেও পাওয়া যায়।
- **বোর্ড:** সব বোর্ড রো এখন subject-wide (chapter/lesson ট্যাগ নেই) → **বিষয়-লেভেলে**, লেসন তালিকার শেষে; ভেতরে বছর/বোর্ড চিপ।
- **ক্যাটাগরি:** বাংলা ১ম → গদ্য/পদ্য/উপন্যাস → পাঠ → ৪ ফর্ম; বাংলা ২য় → ১১টি টাইপ (এখনকার); ইংরেজি ২য় → Paper-II সেকশন; ইংরেজি ১ম → সেট গ্রুপ; গণিত/বিজ্ঞান/ICT → অধ্যায় → লেসন।
- **অতিরিক্ত ফর্ম:** উচ্চতর গণিত/বিজ্ঞানের `exercise`/`activity` আলাদা কার্ড (প্রশ্নের ফরম্যাটই আলাদা)।
- **লেবেল:** “সংক্ষিপ্ত প্রশ্ন (SQ)”।
- **শূন্য কাউন্ট:** কার্ড লুকায়।

## যা বদলেছে (এই কমিট)
- `global_picker_tree.dart`: বিষয়-লেভেলে **Board** ও **Model Test** নোড (শুধু ডেটা থাকলে; বোর্ড খুললে বছর/বোর্ড চিপসহ স্ক্রিন)।
- `search_flow_browse_extras.dart`: প্রতি বিষয়ে subject-wide `boardTotal` লোড।
- `lesson_hub_screen.dart`: কার্ড ডেটা-চালিত — CQ → MCQ → SQ → অতিরিক্ত ফর্ম; বোর্ড/মডেল শুধু থাকলে, “পুরো বিষয়ের” লেবেলসহ।
- `lesson_hub_widgets.dart`: exercise/activity/exercise-MCQ/conceptual-এর নিজস্ব আইকন-রঙ।
- `search_flow_strings.dart`: SQ লেবেল।
