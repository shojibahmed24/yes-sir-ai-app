## অ্যাপে যা দেখা যাবে
1. লেসন হাব → **বোর্ড প্রশ্ন** → MCQ/সৃজনশীল সাবসেকশন
2. **বছর + বোর্ড চিপ** (লাইভ কাউন্ট, ক্রস-ফিল্টার)
3. তালিকার প্রতিটি রো: “ঢাকা বোর্ড ২০২৪ · MCQ” → খুললে **গাইডের চাবি/সমাধান** সহ উত্তর
4. **বোর্ড MCQ কুইজ** — নির্বাচিত বছর/বোর্ডের প্রশ্ন, বিষয়ভিত্তিক
5. সৃজনশীল বোর্ড রো আগের মতো গ্রুপ আকারে (উদ্দীপক + ক/খ/গ/ঘ)
