## আজকের বাস্তবতা (probe)
- books_public: ক্লাস ৬ = ৪৪টি supplied বই, ৭ = ৪৪টি, ৮ = ১১ রো (০ supplied), ৯ = ১৬ (০), ১০ = ১ (০)।
- গাইড (guideChapters math): ক্লাস ৬/৭/৮/৯/১০ — সব ক্লাসেই চ্যাপ্টার+প্রশ্ন আছে।
- অর্থাৎ: ৬–৭ = বই+গাইড, ৮–১০ = গাইড-কেন্দ্রিক। guide-only আনলক (P2) এখন সব ক্লাসে কাজ করবে।

## যা আছে (reuse)
- ক্লাস সিলেক্টর (১–১০) → সাবজেক্ট → চ্যাপ্টার → লেসন → টাইপ: পূর্ণ ফ্লো।
- Subject detail (গণনা+অ্যাকশন), সাবজেক্ট-আইকন/রঙ, গাইড-অনলি আনলক, বাল্ক কী, recent/continue, saved।
