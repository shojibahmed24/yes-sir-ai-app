# Yes Sir AI - Flutter app
Package: com.yessirai.app
Design source: stitch-reference/ (Google Stitch export, Warm Paper Scholar)
HARD RULES:
- Every Dart file MAX 250 lines, target 150-200. Split widgets if over.
- Bangla + English, PAGE-WISE: each page ships with its own lib/l10n/pages/*_strings.dart (bn + en) at build time.
- UI first (login first), then backend. Backend details list is delivered at the end.
- Premium: $5/month, voice 30 min/month, Play Billing only, voice premium-only and isolated.
